Fallstudie

Monatsabschluss: von zwei Tagen auf zwei Stunden.

Ein Projekt im Auftrag eines Dienstleisters, anonymisiert.

2 Tage→2 Stunden
Vorher, per Hand2 Arbeitstage
Nachher, automatisch2 Stunden

Im Maßstab: 2 Arbeitstage = 16 Stunden

7
Quellsysteme angebunden
1
Person war monatlich gebunden
Schrittweise
Erst ein Use Case, danach Gesellschaft für Gesellschaft

Ausgangslage

Sieben Gesellschaften, eine Person, zwei Tage.

Eine Unternehmensgruppe mit sieben Tochtergesellschaften. Jede hatte ihr eigenes Quellsystem. Für den Monatsabschluss hat ein Controller die Zahlen jeden Monat per Hand zusammengetragen und abgestimmt. Das hat zwei Arbeitstage gekostet und hing an genau einer Person.

Vorgehen

Erst ein Use Case, dann Gesellschaft für Gesellschaft.

  • Alle sieben Quellsysteme an eine gemeinsame Datenplattform angebunden.
  • Schrittweise eingeführt: zuerst ein Use Case, danach jede Gesellschaft einzeln.
  • Das Datenmodell ist so gebaut, dass neue Gesellschaften ohne Umbau dazukommen.

Ergebnis

Zwei Stunden, automatisch.

Der Monatsabschluss läuft heute in zwei Stunden statt in zwei Tagen. Die Zahlen kommen aus einer Quelle, und niemand muss mehr von vorn anfangen, wenn eine Gesellschaft dazukommt.
